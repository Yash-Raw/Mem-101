# Entity Fragmentation

One real person, place, or thing scattered across several unlinked records because they were referred to differently: Sam, Samira, Sammy, my partner, she.

## Why it matters in a memory layer

Fragmentation splits the evidence for a fact across records that never meet, so nothing accumulates and no contradiction is ever detected — the system holds four half-pictures instead of one. It is invisible in testing, because any single record looks correct.
