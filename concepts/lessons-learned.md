# Lessons Learned

Consequences the user stated — *if you skip this, that happens* — bound to the step they warn about.

## Why it matters in a memory layer

The conclusion without the consequence is an instruction the system can only repeat. *"The diff step matters most"* can be recited; *"if you skip it the numbers look fine and they aren't"* can be acted on, explained, and argued with — it says the failure is **silent**, which is the entire reason the step matters.

Bind it while both halves are in hand. The trigger is usually a pronoun — *"if you skip **it**"* — referring to the previous sentence, which extraction has already turned into a different memory. Ten minutes later there is no *it* to resolve.

And count before building. This course's corpus states exactly **one** lesson in twenty-four turns; one row does not justify a store. What the count justifies is a change to the write path.
