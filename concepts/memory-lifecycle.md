# The Memory Lifecycle

The loop every memory travels: **extract → store → evolve → retrieve → assemble**, with **govern** wrapped around all of it.

`evolve` is the stage with no counterpart in retrieval systems. A corpus does not change its mind.

## Why it matters in a memory layer

It is this course's spine. Every lesson declares the stage it belongs to, so a reader always knows which part of the machine they are working on and what it connects to. Where a system is failing is usually a question of which stage is missing.
