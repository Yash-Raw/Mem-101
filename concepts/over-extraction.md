# Over-Extraction

Storing everything that could conceivably be a fact, because the extractor was never given a reason to say no.

## Why it matters in a memory layer

Costs compound quietly. Every junk memory is embedded, ranked, and competes for a slot in the token budget forever, so precision at write time buys more than any reranker. It is the failure that feels like success: the store fills up fast and looks healthy.
