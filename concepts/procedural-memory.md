# Procedural Memory

A record of **how to do something**: an ordered workflow, a learned preference about method, a correction that should change future behaviour.

## Why it matters in a memory layer

Procedures break the assumptions the other types are stored under. Order is load-bearing, so chunking destroys them; they are retrieved by task rather than by topic, so semantic similarity finds them at the wrong moments; and they are usually taught once, explicitly, rather than inferred. Storing a procedure as prose and recalling it by cosine similarity returns the steps shuffled.
