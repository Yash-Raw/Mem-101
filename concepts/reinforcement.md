# Reinforcement

A memory earning its place by being used: recalled, assembled into context, and not corrected. Each use buys back some of the age that would otherwise fade it.

## Why it matters in a memory layer

It is the strongest signal available for what matters, and the only one that requires the system to have been running -- which is exactly why it cannot be the only one. A store that ranks purely by past use never surfaces the fact stated once and never asked about until it matters. Distinct from [corroboration](corroboration.md): that is independent sources agreeing a claim is *true*, this is evidence it is *useful*.
