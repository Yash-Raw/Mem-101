# Semantic Memory

A record of **what is currently true**, detached from when it was learned: Priya works at Calico Systems, Priya does not eat meat. It is a belief about the present, and it can go stale.

## Why it matters in a memory layer

This is the type a question usually wants, and the type that needs the most machinery. Because semantic memories claim to describe *now*, two of them can contradict, and something must decide which survives. Every mechanism in the Intermediate level — conflict detection, belief updating, supersession — exists because this type mutates.
