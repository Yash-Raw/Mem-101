# Unnameable Claim

A memory asserting something the system has no slot for — so nothing can ever be compared with it.

## Why it matters in a memory layer

Conflict detection generates candidates by slot, because I3 measured that comparing everything with everything is what slots exist to avoid. A claim naming no slot therefore forms no pair, meets no arbitration, and stays live at whatever confidence it arrived with.

The output is indistinguishable from having survived scrutiny. *"Nothing disagreed with this"* and *"nothing looked at this"* read the same in the store, which is why the count has to be reported rather than inferred.

On this course's corpus **nine of thirty-seven** memories are unnameable and seven are the user's own, so it is a vocabulary gap rather than an agent problem — but it is on agent writes that it stops being a retrieval inconvenience and becomes a question about what you are willing to believe unchecked.
