# User Model

What the store believes about the person, keyed on attributes rather than held as a list of statements.

## Why it matters in a memory layer

Retrieval has no user model, and the absence is not an oversight: a corpus has no subject to be a model of. Here the profile *is* the store — assembled from beliefs written one turn at a time by several parties, some about other people, most already replaced once.

The naive version is every live semantic memory, and its two errors are invisible in a count. On this course's corpus that is **19 statements**, of which **2 are about the user's partner** — an error that will be stated in the first person — and **6 describe nothing the system has a name for**. Keyed on slot, the model is **6 attributes**, and it earns its keep precisely by being smaller than the store.

Return what did not fit. A model that silently omits a third of its input looks exactly like one with nothing to omit.
